# Web 3D Kidnap Typing Game

This project is a browser-based 3D game (Three.js) where the player must type English translations of Arabic words under time pressure.

## Structure

```
web-game/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  ├─ scene.js
│  ├─ game.js
│  ├─ words.js
│  └─ utils.js
├─ assets/
│  ├─ models/
│  ├─ sounds/
│  └─ textures/
└─ README.md
```

## Quick start

1. Upload the `web-game` folder to your web server.
2. Open `index.html` in a browser.
3. (Optional) Add a GLB model named `man.glb` into `assets/models/` for a nicer character. If absent, the game falls back to a blocky character.
